# ADR 0014: Proportional CI and reproducible local analysis

## Status

Accepted for Checkpoint 15.

## Decision

GitHub Actions runs one bounded validation job on pull requests and pushes to `main`. The job uses
the pinned pnpm version and Node engine, installs with `--frozen-lockfile`, verifies canonical
workspace metadata, runs typecheck/lint/unit tests/format checks, exercises one offline fixture and
the analysis command, and builds the web application.

The workflow has read-only repository permissions, no provider credentials, and no provider-backed
steps. Morph and Groq integration tests remain opt-in/manual. Existing provider tests inject
deterministic fetch implementations, so CI can verify response parsing, metadata, error
classification, redaction, and rate-limit behavior without network access or paid quota.

Persisted run analysis remains generated by `pnpm morphscope analysis`; published tables or charts
must be derived from that script output rather than edited by hand.

## Consequences

- A fresh checkout gets the same deterministic checks as the local contributor workflow.
- CI proves the CLI/web vertical slice without secrets or external-service dependence.
- Provider integration evidence is intentionally separate from routine merge validation.
